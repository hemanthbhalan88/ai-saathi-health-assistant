# AI SAATHI 🩺🤖

AI SAATHI is a multilingual AI-powered health assistant designed to help users understand their symptoms through voice or text input. The application supports multiple languages and provides basic health guidance while emphasizing that it is not a substitute for professional medical advice.

## Features

* Voice-based symptom input
* Text-based symptom input
* Multilingual support
* Speech-to-Text using Whisper
* Text-to-Speech responses
* Symptom matching from a medical dataset
* AI-powered fallback responses
* User-friendly Streamlit interface

## Tech Stack

* Python
* Streamlit
* OpenAI Whisper
* gTTS / pyttsx3
* JSON

## Project Goal

To make basic health information more accessible, especially for users who prefer interacting in their native language through voice-based communication.

## Disclaimer

This project is intended for educational purposes only and does not provide medical diagnoses. Users should consult qualified healthcare professionals for medical advice.
